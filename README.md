# GrapeSite

A visual website builder powered by [GrapesJS](https://grapesjs.com), with multi-page editing, symbols, project import/export, and per-page SEO settings.

## Features

- **Multi-page editing** — manage and switch between pages from the left panel
- **Symbols** — reusable components; edits sync across all instances
- **Project import/export** — save and load the whole project as a `.json` file (pages, symbols, assets, styles)
- **Website export** — export the site as a self-contained `.zip` (one HTML file per page)
- **Page Settings** — per-page metadata: title, description, favicon, keywords, Open Graph tags, custom HTML head/body
- **Visual editing** — blocks, layers, styles, properties, assets, preview
